# 十二键电子琴 —— FPGA 实时可视化上位机

> 仿照参考视频里的界面做的 PC 端程序。
> 界面包含：**李萨如图形 / 实时频谱 / 波形显示 / 状态栏 / 12 键钢琴键盘**。
> 纯 Python 实现，只依赖 `tkinter + numpy + matplotlib`（你机器上已装好，无需再装任何东西）。

---

## 一、这个界面属于什么

参考视频里那个是**上位机程序**（PC 桌面应用），不是网页前端。它干三件事：

1. 从 FPGA 通过**串口（UART）**读采样数据和按键状态
2. 在 PC 上算 **FFT**、画**波形**、画**李萨如**
3. 同步显示音色 / 力度 / 声部数 / 效果器等状态

我做的这个是同一类东西，但多了一个**演示模式**：不接板子也能跑，内置信号合成，可以直接录演示视频、截图放 PPT。

## 三、连接真实 FPGA（串口模式）

界面上填串口号（Tang Nano 20K 的 BL616 会枚举出 **COM7 / COM8**，二选一），点"连接"。

⚠ **当前 FPGA 代码还没有串口发送功能**，所以现在连上去只会报"连接失败"或收到无用数据。
要用串口模式，需要在 RTL 里加一个 `uart_stream.v`（见第四节），我可以帮你写。

### 帧协议

每帧 **41 字节**：

| 字节 | 含义 |
|---|---|
| 0 | `0xA5` 帧头1 |
| 1 | `0x5A` 帧头2 |
| 2 | `timbre` 音色 0..3 |
| 3 | `keys` 低 8 位（key0..key7） |
| 4 | `keys` 高 4 位（bit3..0 = key11..key8） |
| 5 | `voices` 活跃声部数 |
| 6 | 界面状态标志（预留） |
| 7 | 效果器开关 0..3 |
| 8..39 | **32 个采样**，`uint8`，0x80 为中心（取值 0..255） |

- 采样率与 FPGA 一致：`52734.375 Hz`
- 32 样本/帧 → 帧率约 1648 帧/秒，**波特率需要 921600**
- 如果板子只能跑 115200，就把每帧样本数从 32 降到 8（同时改 `FRAME_LEN` 和 `f[8:40]`）

## 四、想改的地方在哪

| 想改什么 | 改哪里 |
|---|---|
| 采样率 | 文件顶部 `FS = 52734.375` |
| 显示多少个样本 | `N_SAMPLES = 512` |
| 键名 / 引脚 / 频率 | `NOTE_NAMES` / `NOTE_PINS` / `NOTE_HZ` |
| 哪些是黑键 | `IS_BLACK` |
| 配色 | `C_WAVE`、`C_SPEC`、`C_ACCENT` 等常量 |
| 音色名字 | `TIMBRE_NAMES` |

## 五、和参考视频的差异（如实说明）

| 项 | 参考视频 | 本程序 |
|---|---|---|
| 数据来源 | FPGA 实时串口 | 演示模式：PC 端合成；串口模式：等 RTL 配合 |
| 李萨如 | 有 | 有（信号 vs 1/4 周期延迟） |
| 实时频谱 | 有 | 有（32 个对数频带 FFT） |
| 波形 | 有 | 有 |
| 键盘高亮 | 有 | 有（点哪亮哪，蓝色） |
| 音色/力度/声部状态 | 有 | 有 |
| 音频效果、演奏效果下拉 | 有 | 有（界面层，未接音频处理） |
