## 本轮新增模块（复音架构）

| 文件 | 功能 |
|---|---|
| osc_voice.v | 单声部振荡器（DDS 相位累加 + 方波 + 包络调制） |
| oscillator_array.v | 振荡器阵列（generate 例化 N 份） |
| note_alloc.v | 音符分配器（note-on/off、复用、抢占） |
| mix_tree.v | 混音器（求和 + 饱和，防削波） |
| adsr.v | ADSR 包络发生器（四段状态机） |
| synth_top.v | 复音合成器顶层（整合全部链路） |

## 测试平台

| 文件 | 覆盖 |
