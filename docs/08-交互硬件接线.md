# 08 · 交互硬件接线指南

> 板卡：Sipeed Tang Nano 20K（GW2AR-18），**所有 IO 都是 3.3V 电平**
> 对应赛题要求：「至少 2 个独立可控演奏维度」

---

## 一、四样东西分别干什么

| 元件 | 输出类型 | 难度 | 建议用途 | 用几个 |
|---|---|---|---|---|
| **TTP223 触摸模块** | 数字（已经整形好） | ⭐ 最简单 | **维度 1：选音（琴键）** | 5~8 个 |
| **红外避障模块**（LM393） | 数字（已经整形好） | ⭐ 简单 | **维度 2：无接触手势**（控音量/弯音） | 1~3 个 |
| **6×6×5 轻触开关** | 干接点（纯机械） | ⭐ 简单 | 复位 / 模式切换 / 八度切换 | 2~3 个 |
| **红外对管（裸件）** | **模拟量**，需要自己搭电路 | ⭐⭐⭐ 最难 | 国赛阶段做机械琴键的光闸 | 备用 |

**结论：现在先用前三个。裸对管先放着**（原因见第五节）。

---

## 二、接线前必须记住的 3 条铁律

### 铁律 1：全部用 3.3V 供电，不要用 5V

FPGA 的 IO 是 **3.3V 电平**，灌 5V 进去会打坏 IO。

| 模块 | 标称供电 | 我们接 |
|---|---|---|
| TTP223 | 2.5~5.5V | **3V3** |
| 红外避障模块 | 3~5V | **3V3** ⚠️ 特别重要，见下 |
| 轻触开关 | 无源 | — |

> ⚠️ **避障模块为什么必须用 3.3V**：它的 OUT 是 **LM393 开集输出**，
> 靠一个上拉电阻拉到 VCC。**如果用 5V 供电，OUT 的高电平就是 5V**，
> 直接怼进 FPGA 的 3.3V IO —— 这是最容易烧板子的一种接法。

### 铁律 2：所有 GND 必须连到一起

模块的 GND 和板子的 GND 不连通，信号就是"悬空比较"，读数会乱跳或不响应。

### 铁律 3：每个信号脚都要在 `.cst` 里配上下拉

悬空的输入脚会自己乱飘，代码里会读到随机值。具体配置见各节。

## 三、逐个接线

### 3.1 TTP223 电容触摸模块（维度 1：琴键）

**模块上的孔丝印**：`GND` / `I/O` / `VCC`（板子上直接印着，不用猜）

| 模块 | Tang Nano 20K |
|---|---|
| VCC | **3V3** |
| GND | **GND** |
| I/O | 一个空闲 FPGA IO（见第七节分配表） |

**A / B 跳线怎么设**（模块上有两个小焊点）：

| 效果 | B 点 | A 点 | 我们要吗 |
|---|---|---|---|
| **点动高电平输出** | 不焊 | 不焊 | ✅ **默认就是这个，不用动** |
| 自锁高电平输出 | 焊 | 不焊 | ❌ |
| 点动低电平输出 | 不焊 | 焊 | ❌ |
| 自锁低电平输出 | 焊 | 焊 | ❌ |

> **点动高电平** = 手指按住时输出高电平，松开变低。
> 这正是琴键需要的：按住发声、松开停声。

**`.cst` 约束**（用一个空闲 IO 举例）：
```
IO_LOC "touch[0]" 25;
IO_PORT "touch[0]" IO_TYPE=LVCMOS33 PULL_MODE=DOWN BANK_VCCIO=3.3;
```

**⚠️ 三个容易踩的坑**：
1. **上电瞬间手指不能碰触摸片** —— TTP223 上电时会自校准，有手指在上面就把它当成"常态"，之后就一直误判。上电时手拿开
2. **TTP223 输出的是"电平"，不是"脉冲"** —— 代码里必须做**边沿检测**：
   上升沿 = 按下（发 note-on），下降沿 = 松开（发 note-off）。不能直接把电平当触发用
3. 每个模块的 I/O 各占一个 FPGA IO，5 个键就要 5 个 IO

---

### 3.2 红外避障传感器模块（维度 2：无接触手势）

**模块上的针**：`VCC` / `GND` / `OUT`

| 模块 | Tang Nano 20K |
|---|---|
| VCC | **3V3**（不是 5V！） |
| GND | **GND** |
| OUT | 一个空闲 FPGA IO |

**输出极性**：检测到前方有物体（2~30cm）时，**OUT 输出低电平**。

**`.cst` 约束**（开集输出，建议上拉）：
```
IO_LOC "ir_gesture" 30;
IO_PORT "ir_gesture" IO_TYPE=LVCMOS33 PULL_MODE=UP SINGLE_RESISTOR=ON BANK_VCCIO=3.3;
```
代码里读到 0 = 有手，读到 1 = 没手。（也可以写成 `~ir_gesture` 变成高有效）

**用法建议**：

| 方案 | 做法 | 效果 |
|---|---|---|
| 简单版 | 手靠近 → 翻转一个标志位 | 控音量档 / 开关颤音 |
| **进阶版（推荐）** | 手在传感器前**来回挥动**，测量两次触发的**时间间隔**，映射成音高 | **特雷门琴（theremin）式弯音**，答辩非常加分 |

**⚠️ 注意事项**：
1. 蓝色电位器是**检测距离调节**（顺时针 = 变远）。**出厂已经调好，别乱转**；
   要调的话一次转 10°，边转边试
2. 这是**反射式**检测，靠物体反光：
   - **黑色物体测不到**（吸红外），白色最远
   - 大面积比小面积远
3. 检测角度约 35°，装的时候让传感器的"眼睛"正对着演奏方向
4. 想做成"距离分档"：**买 2~3 个模块，把电位器调成不同阈值**，
   手从远到近依次触发 → 得到 3 档距离 → 音量 3 档。比一个模块好用得多

### 3.3 6×6×5 轻触开关

**4 个脚，内部是两对常通**：1-2 是一组，3-4 是一组，按下时两组导通。

**最省线的接法（一端接地法）**：

| 开关 | 接到 |
|---|---|
| 任意一个脚（在 1-2 组里） | **GND** |
| 对角的一个脚（在 3-4 组里） | 一个空闲 FPGA IO |

```
        ┌──── 3V3（不用接！用 IO 内部上拉代替）
        │
FPGA IO ┤
        │
        ├── 开关 ── GND
```
**不用外接上拉电阻**，用 FPGA 内部的：`PULL_MODE=UP`。

```
IO_LOC "key_mode" 31;
IO_PORT "key_mode" IO_TYPE=LVCMOS33 PULL_MODE=UP SINGLE_RESISTOR=ON BANK_VCCIO=3.3;
```

**读值**：未按下 = 1，按下 = 0（**低电平有效**）。

**⚠️ 三个坑**：
1. **插面包板时开关要跨过中间的凹槽**，四个脚分插在凹槽两侧。
   否则 1-2 和 3-4 会被面包板内部连起来，等于常按不放
2. 必须**消抖**：机械开关按下/松开瞬间会抖动 5~20ms，不加消抖会一次按键触发好几次
3. 选对角的两组脚（比如 1 和 3），不要选同一组的两个脚，否则永远是短路的

### 3.4 红外对管（裸件）—— 现在先别用

#### 发射管（透明那根）：必须串限流电阻

**绝对不能把发射管直接接到 3.3V 或 IO 上，会瞬间烧掉。**

```
FPGA IO ──[220Ω]── 发射管 长脚(正极) ── 短脚(负极) ── GND
```

- 长脚 = 正极（阳极），短脚 = 负极（阴极）
- 限流电阻 **220Ω**：电流 = (3.3V − 1.3V) / 220Ω ≈ **9mA**
  - 参数表上限是 30mA，9mA 很安全
  - 用 470Ω 也行（约 4mA），会暗一点
- FPGA IO 直接驱动就行（驱动能力 8~24mA，够）

#### 接收管（黑色那根）：是**模拟器件**，FPGA 读不了

接收管是个光敏二极管，输出的电流随光照连续变化，**不是 0/1**。
而 **GW2AR-18 芯片内部没有 ADC**，FPGA 无法直接读。

标准接法需要**再加一个比较器**：

```
3V3 ── 接收管(反向) ──┬── 1MΩ ── GND
                      │
                      └──→ LM393 比较器 ──→ FPGA IO
                             (另一端接参考电压电位器)
```

#### 所以：建议现在不要用裸对管

- **红外避障模块内部已经有一整套**：发射管 + 接收管 + LM393 + 电位器，
  直接输出数字信号给 FPGA。要做红外检测，**用它就行，不用自己搭**
- 裸对管留给**国赛阶段做机械琴键的光闸**（琴键上装挡片，挡住对射光路 = 触发），
  那时候再用，配合 LM393 或槽型光电开关

**如果要自己搭，还需要买**：LM393 比较器模块、220Ω ×5、1MΩ ×5、10kΩ ×10。

## 四、汇总接线表

| 模块 | VCC | GND | 信号脚 → FPGA |
|---|---|---|---|
| TTP223 #1~#5 | 3V3 | GND | `touch[0..4]` → 25, 26, 27, 28, 29 |
| 红外避障模块 #1 | 3V3 | GND | `ir_gesture` → 30 |
| 红外避障模块 #2（可选） | 3V3 | GND | → 77 |
| 轻触开关 #1（模式切换） | — | GND | `key_mode` → 31 |
| 轻触开关 #2（备用） | — | GND | `key_reset` → 74 |
| I2S DAC | 3V3 | GND | 54 / 55 / 56 |

> 💡 **3V3 / GND 排针不够用**怎么办：
> 用一根杜邦线把面包板的电源轨接到板子的 3V3，所有模块的 VCC 都插在面包板电源轨上。
> GND 同理。这样只需要从板子引 1 根 3V3 + 1 根 GND。

## 六、接完之后的验证顺序

**一次只接一个模块，验证通过再接下一个。** 不要五六个一起上，出问题查不出来。

```
□ 断电接线（带电插拔杜邦线容易打坏 IO）
□ 只接 1 个 TTP223：VCC/GND/I/O 三根，确认没接反
□ 用万用表量模块 VCC 对 GND ≈ 3.3V，确认接的是 3V3 不是 5V
□ 写一个最简单的工程：把 touch[0] 直接连到 led[0]，下载
□ 手指按住 → LED 灭（板载 LED 低电平点亮）；松手 → LED 亮
   → 通了，再往下接
□ 把剩下的触摸模块逐个接上，每接一个复测一次
□ 再单独验证红外避障模块
```

## 七、代码上要做的事（下一阶段，不是接线问题）

接线通了之后，每个元件的代码要求不一样：

| 元件 | 代码要做的处理 |
|---|---|
| TTP223 | **边沿检测**（上升沿=note-on，下降沿=note-off） |
| 红外避障 | **取反**（低有效）+ 需要的话测**触发间隔**做弯音 |
| 轻触开关 | **消抖** 10~20ms + 边沿检测 |
| 红外对管 | 需外部比较器先整形 |

这些模块我们下一步一起写。
