# 05 · 模块规格与接口定义

> 本文件定义乐器方案所有 Verilog 模块的接口、参数与实现要点。
> **接口一旦定下就不要随意改**——模块解耦是复音能顺利扩展的前提。

---

## 一、系统接口总览

```
                    ┌─────────────────────────────────────┐
  交互输入 ────────►│                                     │
   (按键/触摸/ADC)   │           synth_top                 │
                    │                                     │
                    │  交互采集 → 音符分配 → 振荡器阵列    │
                    │            → 混音 → 效果 → I2S      │──► BCK/LRCK/DIN → DAC
                    │                                     │
  复位/时钟 ───────►│                                     │
                    └─────────────────────────────────────┘
                                        │
                                        └──► HDMI（可选：频谱显示）
```

### 顶层端口定义

```verilog
module synth_top (
    input  wire        clk,          // 27MHz 板载时钟
    input  wire        rst_n,        // 复位（引脚 88）
    // ---- 交互输入 ----
    input  wire        key_mode,     // 模式/音色切换（引脚 87）
    input  wire [7:0]  touch,        // 8 路电容触摸
    input  wire        force_adc,    // 力度（可选，ADC 或比较器）
    // ---- I2S 输出 ----
    output wire        i2s_bck,
    output wire        i2s_lrck,
    output wire        i2s_din
);
```

## 二、模块详细规格

### 2.1 `clk_div.v` —— 时钟分频（已实现 ✅）

| 项 | 内容 |
|---|---|
| 文件 | `code/rtl/clk_div.v` |
| 功能 | 产生周期性单周期脉冲（tick） |
| 参数 | `CNT_MAX` 计数上限 |
| 端口 | `clk, rst_n → tick` |
| 乐器用途 | 产生 **48kHz 采样使能**（`CNT_MAX = 562`） |

```verilog
clk_div #(.CNT_MAX(562)) u_audio_tick (
    .clk(clk), .rst_n(rst_n), .tick(audio_en)   // audio_en: 48kHz 单周期脉冲
);
```

**设计要点**：**不要用分频后的时钟去驱动逻辑**，只产生使能信号。这样整个设计只有一个时钟域（27MHz），彻底避免跨时钟域问题。

### 2.2 `debounce.v` —— 按键消抖（已实现 ✅）

| 项 | 内容 |

| 参数 | `CNT_MAX`（消抖时间）、`ACTIVE_LOW`（按下极性） |

| 乐器用途 | 触摸/琴键的稳定检测、边沿触发 |

### 2.3 `i2s_tx.v` —— I2S 发送（🔴 W1 核心）

| 项 | 内容 |
|---|---|
| 功能 | 把并行音频样本串行化为 I2S 格式 |
| 参数 | `DATA_BITS`（默认 16）、`BCK_DIV`（BCK 分频系数） |

**端口**

```verilog
module i2s_tx #(
    parameter DATA_BITS = 16
)(
    input  wire                  clk,        // 27MHz 主时钟
    input  wire                  rst_n,
    input  wire                  sample_en,  // 48kHz 使能
    input  wire [DATA_BITS-1:0]  sample_l,   // 左声道样本
    input  wire [DATA_BITS-1:0]  sample_r,   // 右声道样本
    output reg                   bck,        // 位时钟 ≈3.072MHz
    output reg                   lrck,       // 声道时钟 48kHz
    output reg                   din         // 串行数据
);
```

**I2S 时序要点**

| 信号 | 频率 | 说明 |
|---|---|---|
| BCK | fs × 32 × 2 = **3.072 MHz** | 每个 bit 一个时钟 |
| LRCK | fs = **48 kHz** | 低=左声道，高=右声道 |
| DIN | — | **MSB first**，LRCK 变化后延迟 1 个 BCK 输出 |

> ⚠️ I2S 标准是 **MSB first 且比 LRCK 延迟一个 BCK**（Philips 标准）。写错会导致左右声道错位或无声。

**实现要点**：
1. 用主时钟分频产生 BCK（`27MHz / 3.072MHz ≈ 8.8`，取整数分频）
2. LRCK 由 BCK 计数 32 个周期翻转
3. 在 BCK 下降沿更新 DIN（保证接收端在上升沿稳定采样）

### 2.4 `wave_rom.v` —— 波形表 ROM（🔴 W2）

| 项 | 内容 |
|---|---|
| 功能 | 存储波形采样点，供查表 |
| 参数 | `ADDR_BITS = 10`（1024 点）、`DATA_BITS = 12` |

```verilog
module wave_rom (
    input  wire                  clk,
    input  wire [9:0]            addr,
    output reg  [11:0]           data
);
    reg [11:0] rom [0:1023];
    initial $readmemh("sine_1024x12.mi", rom);
    always @(posedge clk) data <= rom[addr];
endmodule
```

**关键设计：波形 ROM 必须全阵列共享**
- 32 个振荡器共用一份 ROM（约 12Kbit），而不是各存一份
- 这是省 BSRAM 的核心手段

**波形表生成**（Python 脚本，见 `code/tools/gen_wave.py`）：
- 正弦波：`round((sin(2πi/1024) + 1) / 2 × 4095)`
- 其他波形可直接生成三角波、锯齿波、方波表

### 2.5 `phase_acc.v` / `osc.v` —— 振荡器（🔴 W2）

| 项 | 内容 |
|---|---|
| 功能 | DDS 相位累加 + 查表 + 包络 |
| 参数 | `PHASE_BITS = 32`、`ADDR_BITS = 10` |

**核心原理**

```
每个采样周期（audio_en 有效时）：
    phase <= phase + fcw          // 32 位累加，自然溢出
    addr   = phase[31:22]         // 取高 10 位作表地址
    wave   = rom[addr]            // 查表
    out    = wave × envelope      // 施加包络（用移位实现）
```

**频率控制字公式**

```
fcw = f_out × 2^PHASE_BITS / fs
```

**常用音符 FCW（PHASE_BITS=32, fs=48000）**

| 音符 | 频率 Hz | FCW |
|---|---|---|
| C4 | 261.63 | 23408735 |
| D4 | 293.66 | 26278123 |
| E4 | 329.63 | 29500903 |
| F4 | 349.23 | 31255917 |
| G4 | 392.00 | 35084356 |
| A4 | 440.00 | 39370534 |
| B4 | 493.88 | 44198394 |
| C5 | 523.25 | 46819261 |

> 建议用 Python 脚本（`code/tools/gen_note_table.py`）生成完整音符表，避免手算出错。

### 2.6 `adsr.v` —— 包络发生器（🔴 W4）

| 项 | 内容 |
|---|---|
| 功能 | 四段包络：Attack / Decay / Sustain / Release |
| 参数 | 四段的时长（时钟数）、Sustain 电平 |

**端口**

```verilog
module adsr #(
    parameter ATK_STEP = ...,
    parameter DEC_STEP = ...,
    parameter SUS_LEVEL = 8'd128,
    parameter REL_STEP = ...
)(
    input  wire        clk,
    input  wire        rst_n,
    input  wire        sample_en,   // 48kHz 使能
    input  wire        note_on,     // 按下
    input  wire        note_off,    // 松开
    output reg  [7:0]  env          // 0~255
);
```

**状态机**

```
IDLE ──note_on──► ATTACK ──到最大──► DECAY ──到SUS──► SUSTAIN
                      ▲                                   │
                      │                              note_off
                      │                                   ▼
                      └──────────── note_on ◄────── RELEASE
```

**实现要点**：包络值用**移位加法**逼近，不用乘法器——48 个 DSP 不够 32 个振荡器各占一个。

---

### 2.7 `note_alloc.v` —— 音符分配器（🔴 W5）

| 项 | 内容 |
|---|---|
| 功能 | 管理 note-on / note-off，分配空闲声部 |
| 参数 | `VOICE_NUM`（复音数） |

**端口**

```verilog
module note_alloc #(
    parameter VOICE_NUM = 8
)(
    input  wire                     clk,
    input  wire                     rst_n,
    input  wire [7:0]               note_in,      // 音符编号
    input  wire                     note_valid,   // 有按键事件
    input  wire                     note_on,      // 1=按下 0=松开
    output reg  [VOICE_NUM-1:0]     voice_en,     // 各声部使能
    output reg  [VOICE_NUM*8-1:0]   voice_note    // 各声部音符
);
```

**分配策略（按优先级）**

1. 优先找完全空闲的声部
2. 没有空闲时，抢占**最早分配**的声部（防止卡音）
3. 同一音符再次按下时，复用到原声部

### 2.8 `voice_array.v` —— 振荡器阵列（🔴 W5）

| 项 | 内容 |
|---|---|
| 功能 | 用 `generate` 例化 N 个振荡器 |
| 参数 | `VOICE_NUM` |

**关键**：**改 `VOICE_NUM` 一个数字，复音数就变**，不要写重复代码。

```verilog
genvar i;
generate
    for (i = 0; i < VOICE_NUM; i = i + 1) begin : gen_voice
        osc u_osc (
            .clk       (clk),
            .rst_n     (rst_n),
            .sample_en (sample_en),
            .fcw       (voice_fcw[i]),
            .env       (voice_env[i]),
            .wave_sel  (timbre),
            .sample    (voice_sample[i])
        );
    end
endgenerate
```

### 2.9 `mix_tree.v` —— 混音器（🔴 W5）

| 项 | 内容 |
|---|---|
| 功能 | N 路样本相加 + 饱和处理 |
| 参数 | `VOICE_NUM`、`IN_BITS`、`OUT_BITS` |

**端口**

```verilog
module mix_tree #(
    parameter VOICE_NUM = 8,
    parameter IN_BITS   = 12
)(
    input  wire                              clk,
    input  wire                              rst_n,
    input  wire [VOICE_NUM*IN_BITS-1:0]      samples_in,
    output reg  [IN_BITS+3:0]                sample_out   // 扩展位宽
);
```

**设计要点**
1. **位宽扩展**：N 路相加需要 `IN_BITS + log2(N)` 位，否则溢出
2. **饱和处理**：超过上限时钳位，而不是回绕（回绕会产生刺耳噪声）
3. **流水线**：加法树分级寄存，保证时序收敛

### 2.10 `test_mode.v` —— 合规自证模式（🔴 W5）

| 项 | 内容 |
|---|---|
| 功能 | 输出 N 路等间隔不同频率，供频谱验证 |
| 参数 | `VOICE_NUM` |

**用途**：题目要求现场"频谱可观测对应数量独立谱峰"。按一个键进入此模式，输出 N 个间隔 200Hz 的频率。

**验收**：频谱上应看到 N 个清晰的独立峰。

## 三、时钟与资源规划

### 3.1 时钟域（只有一个！）

| 信号 | 频率 | 产生方式 |
|---|---|---|
| 主时钟 `clk` | 27 MHz | 板载晶振（引脚 4） |
| 音频使能 `sample_en` | 48 kHz | `clk_div` 产生单周期脉冲 |
| BCK | 3.072 MHz | `i2s_tx` 内部分频 |
| LRCK | 48 kHz | `i2s_tx` 内部计数 |

> **整个设计只用一个时钟域**。`sample_en` 只是使能信号，不是时钟。

### 3.2 资源预算（复音 8 的估算）

| 模块 | LUT | BSRAM | DSP |
|---|---|---|---|
| I2S 发送 | ~100 | 0 | 0 |
| 波形 ROM（共享） | ~50 | ~12Kb | 0 |
| 振荡器 ×8 | ~800 | 0 | 0 |
| ADSR ×8 | ~800 | 0 | 0 |
| 混音器 | ~200 | 0 | 0 |
| 交互采集 | ~300 | 0 | 0 |
| **合计** | **~2250（11%）** | **~12Kb（1.5%）** | **0** |
| 复音 32 估算 | ~8000（39%） | ~12Kb | 0 |

**结论**：复音 32 在 GW2AR-18 上可行，但需注意时序收敛。

## 四、编码规范（团队统一）

1. **所有时序逻辑用非阻塞赋值 `<=`**，组合逻辑用 `=` 或 `assign`
2. **模块名小写，信号名小写，参数名大写**
3. **每个模块必须有文件头注释**：功能、参数、端口说明
4. **复位统一低有效**（`rst_n`）
5. **不使用 `initial` 除 ROM 初始化外**
6. **不使用门级原语**，用行为描述
7. **文件名纯英文小写**，不用中文和空格
