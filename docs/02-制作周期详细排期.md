# W2（09-29 ~ 10-05）单振荡器（DDS）
## 🔴 目标：440Hz 正弦波，频谱可见主峰

| 天 | 任务 | 验收标准 |
|---|---|---|
| D1 | 用 Python 生成正弦波形表 ROM 初始化文件（1024 点 × 12bit，`.mi` 格式） | 文件生成，内容可读 |
| D1 | 在 Gowin 里实例化波形 ROM（IP Core 或 `$readmemh`） | 综合通过 |
| D2 | 实现**相位累加器**：32 位，每个采样周期加 FCW | 仿真波形正确 |
| D3 | 相位高位 → ROM 地址 → 取出样本 → 送 I2S | 仿真输出正弦序列 |
| D4 | 上板：输出固定 440Hz | **手机频谱 App 显示 440Hz 主峰** |
| D5 | 参数化 FCW，试不同频率（220 / 440 / 880Hz） | 频率准确，误差 <1% |
| D6 | 加一个简单音量控制（移位实现） | 音量可调，不爆音 |
| D7 | 复盘：把 I2S + DDS 封装成可复用模块，加注释 | 模块接口清晰，可被其他模块调用 |

**产出**：能输出任意标准音高正弦波的振荡器。

# W3（10-06 ~ 10-12）音符映射 + 2 维交互
## 🔴 目标：能弹音阶，两个独立维度可用

| 天 | 任务 | 验收标准 |
|---|---|---|
| D1 | 建立音符→FCW 查找表（至少 1 个八度，12 个半音） | 表中数值经计算验证 |
| D2 | 板载按键（引脚 87）映射到音符 | 按键能改变音高 |
| D3 | **交互维度 1**：自制电容触摸（RC 充放电 + 计数器测时间） | 手指触摸能触发，不误触 |
| D4 | 触摸做成 4–8 个音符键位 | 不同键位发不同音 |
| D5 | **交互维度 2**：光电感应或第二组触摸/按键 | 第二个维度独立可控 |
| D6 | 两个维度组合使用（如：一个选音、一个控制音量或音色） | 组合逻辑正确，不互相干扰 |
| D7 | 能弹一段简单旋律 | 录视频为证 |

**产出**：能弹奏的简易电子琴。

# W4（10-13 ~ 10-19）ADSR 包络
## 🔴 目标：声音有起音/衰减/保持/释放

| 天 | 任务 | 验收标准 |
|---|---|---|
| D1 | 设计 ADSR 状态机（4 段 + IDLE） | 状态转换图清晰 |
| D2 | 实现 Attack（音量 0→最大，可调时长） | 听到渐强起音 |
| D3 | 实现 Decay（最大→保持电平） | 听到衰减 |
| D4 | 实现 Sustain（保持）+ Release（松开后衰减到 0） | 松键后声音自然消失，不硬切 |
| D5 | 包络值用**移位加法**实现（避免占用 DSP） | 综合报告显示 DSP 占用低 |
| D6 | 参数可调（4 段时长各 2–4 档） | 能切换不同包络 |
| D7 | 对比有无包络的听感差异，录视频 | 差异明显 |

**产出**：具备 ADSR 的音色，听感明显改善。

> 💡 本项直接影响评分中"ADSR 包络调控"这一条，也是"听起来像乐器"的关键。

# W5（10-20 ~ 10-26）复音 4（架构定型）
## 🔴 目标：同时 4 音，频谱 4 个独立谱峰

| 天 | 任务 | 验收标准 |
|---|---|---|
| D1 | **把振荡器改成 `parameter VOICE_NUM` + `generate`** | 改一个数字就能改复音数 |
| D1 | 波形 ROM 改为**全阵列共享** | 综合报告 BSRAM 占用不随复音数线性增长 |
| D2 | 实现音符分配器：note-on 时找空闲声部，note-off 时释放 | 仿真验证分配逻辑 |
| D3 | 实现声部仲裁（超出复音数时的抢占策略） | 不出现"卡音" |
| D4 | 实现**混音加法树**（流水线 + 饱和处理） | 多音同时响不失真 |
| D5 | 复音 4 上板调试 | **同时按 4 键，频谱出现 4 个独立谱峰** |
| D6 | 加**测试模式**（一键输出 N 路不同频率，用于合规自证） | 测试模式下频谱峰数 = 复音数 |
| D7 | 时序检查：看综合报告，确认无时序违例 | 无 setup/hold 违例 |

**产出**：复音 4 的合成器 —— **这是省赛最小可交付版本**。

> ⚠️ 本周是整个项目的架构定型周。如果 D7 复音 4 仍不稳定，省赛就交付到 W3 的水平（简易电子琴），并把复音放到国赛。
