# 8 路触摸键盘扩展板 —— 原理图设计包
## 用于 Tang Nano 20K 复音合成器

> 目标：把「2 个板载按键」扩展成「8 路触摸键」，做出真正能演奏的电子琴
> 工具：嘉立创EDA（画原理图/PCB）或洞洞板手工焊接
> 版本：v1.0 ｜ 2026-10-08

---

## 一、方案选型

### 推荐：TTP223 分立方案

| 方案 | 成本 | 焊接难度 | 可靠性 | 推荐度 |
|---|---|---|---|---|
| **TTP223 芯片 ×8（分立）** | 约 12 元 | 中（需焊 SOP8） | 高 | ★★★★★ |
| TTP223 成品模块 ×8 | 约 32 元 | 低（插杜邦线） | 高 | ★★★★ |
| 自制 RC 充放电触摸 | 约 5 元 | 低 | **低（易受干扰）** | ★★ |
| 机械按键 ×8 | 约 5 元 | 低 | 高但手感差 | ★★★ |

**为什么推荐 TTP223**：
1. 题目要求「自研交互方案」——**触摸是明确列出的合规方案之一**
2. 单芯片方案，输出就是数字电平，FPGA 直接读，不需要 ADC
3. 稳定可靠，不依赖软件调参（自制 RC 方案受温湿度影响大）
4. 成本极低

> ⚠️ **务必选 TTP223（不是 TTP223B）**
> TTP223 默认输出**高电平有效**（触摸=1），TTP223B 相反（触摸=0）。
> 两者可通过焊盘改，但买错会增加调试成本。

## 三、电路原理（ASCII 原理图）

### 3.1 单路触摸键电路（×8）

```
            +3.3V
              │
              ├──────┬───────┐
              │      │       │
           [C1]    [R1]   ┌──┴──────────┐
           100nF   10k   │  TTP223     │
              │      │   │             │
              │      └───┤ VCC     OUT ├────► FPGA GPIO
              │          │             │
              │      ┌───┤ GND     AHLB├──┐
              │      │   │             │  │
              │      │   │  PAD        │  │  (AHLB 决定高/低有效)
              │      │   │   │         │  │
              │      │   │   │         │  │
             GND    GND  │   │         │  │
                         │   │         │  │
                         │   │         │  │
                         │  ═╪═        │  │
                         │   触摸电极  │  │
                         │  (铜箔/焊盘)│  │
                         └─────────────┘  │
                                          │
                                   (见下方说明)
```

**关键元件说明**：

| 元件 | 值 | 作用 |
|---|---|---|
| **U1~U8** | TTP223 (SOT23-6) | 触摸检测芯片 |
| **C1~C8** | 100nF (0.1μF) | 电源去耦，**每个芯片都要有** |
| **R1~R8** | 10kΩ | 可选，OUT 上拉（TTP223 输出足够，仅保守设计） |
| **触摸电极** | 铜箔 10×10mm | 手指触摸区域 |

### 3.2 触摸电极的做法（3 种，按可用性选）

```
方案 A：PCB 焊盘（最专业）
  在扩展板上直接做 8 个 10×10mm 的覆铜焊盘，
  焊盘接 TTP223 的 PAD 引脚，上面盖一层薄亚克力/胶带做绝缘。

方案 B：铜箔片（最快）
  剪 8 片 10×10mm 铜箔胶带，贴在亚克力板背面，
  用导线连到 TTP223 的 PAD 引脚。

方案 C：导电材料（最省）
  硬币、铝箔、甚至回形针都可以做电极 —— 只要能导电且面积够大。
```

**电极接法**：
```
TTP223 的 PAD 引脚 ──── 导线 ──── 触摸电极（铜箔/焊盘）
```
电极**不要**同时接 GND 或 3.3V，它是独立的感应端。

## 四、完整接线表（照这个接就行）

### 4.1 电源分配

| 网络 | 来源 | 去向 |
|---|---|---|
| `+3.3V` | Tang Nano 20K 的 **3.3V 排针** | 8 个 TTP223 的 VCC + 8 个 100nF 电容 |
| `GND` | Tang Nano 20K 的 **GND 排针** | 8 个 TTP223 的 GND + 8 个电容 + 扩展板地 |

> ⚠️ **供电能力检查**：TTP223 工作电流约 1.5mA，8 个共约 12mA。
> Tang Nano 20K 的 3.3V 输出（来自 USB 供电）通常可提供 100mA 以上，
> **12mA 完全安全**。但如果同时接了其他外设，注意总电流。

### 4.2 信号线（8 路）

| 通道 | TTP223 编号 | 输出接到 FPGA | 对应音符 | 音名 |
|---|---|---|---|---|
| 0 | U1 | 25 | 0 | C4 |
| 1 | U2 | 26 | 2 | D4 |
| 2 | U3 | 27 | 4 | E4 |
| 3 | U4 | 28 | 5 | F4 |
| 4 | U5 | 29 | 7 | G4 |
| 5 | U6 | 30 | 9 | A4 |
| 6 | U7 | 31 | 11 | B4 |
| 7 | U8 | 32 | 12 | C5 |

> ⚠️ **引脚号需最终确认**：上表是初步规划，**必须对照 Tang Nano 20K 的
> 引脚定义表核实**（`docs/07-接线指南.md`），确保这些引脚：
>   1. 在 40pin 扩展口上可用
>   2. 没有被板载外设（HDMI、Flash、LED 等）占用
>   3. 属于同一个 IO Bank（避免电平冲突）

### 4.3 去耦电容接法（每个 TTP223 一个）

```
TTP223 的 VCC ──┬── 100nF ──┬── GND
                │           │
              3.3V        地
```
**电容尽量靠近芯片**（走线 < 5mm），否则去耦效果大打折扣。

## 七、关于输出极性（AHLB 引脚）

TTP223 的 `AHLB` 引脚决定输出极性：

| AHLB 接法 | 触摸时 OUT | 适用 |
|---|---|---|
| 接 GND | **高电平（1）** | ✅ 本项目（与代码 `ACTIVE_LOW=0` 一致） |
| 接 VCC | 低电平（0） | 需改代码 |

**本项目的 `debounce` 模块配置**：
```verilog
debounce #(
    .CNT_MAX    (270_000),
    .ACTIVE_LOW (0)      // 0 = 按下为高电平 → 匹配 TTP223 默认
)
```

> 如果实际接法是低有效，只需把 `ACTIVE_LOW` 改成 `1`，不用改硬件。
