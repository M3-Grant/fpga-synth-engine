## 二、第 1 批详细（立即执行）

### 2.1 I2S DAC 模块 —— 最关键的一件

**首选：PCM5102A 模块**

| 项目 | 说明 |
|---|---|
| 淘宝搜索词 | `PCM5102A I2S DAC 模块` |
| 参考价 | 20–50 元 |
| 输出 | 3.5mm 耳机口 |
| 逻辑电平 | 3.3V（**与 Tang Nano 20K 匹配，无需电平转换**） |

**购买前必须确认的 4 件事**：
1. ✅ **是否需要 MCLK（主时钟）**——优先选"3 线 I2S、不需 MCLK"的版本，可省一个 IO 和一路时钟
2. ✅ 是否带 3.5mm 输出口（有的只给焊盘）
3. ✅ 供电范围（3.3V 或 5V）
4. ✅ 是否已焊好排针

**接线（只有 3 根信号 + 电源 + 地）**：

| DAC 侧 | 接到 | 说明 |
|---|---|---|
| BCK | FPGA 自定义 IO | 位时钟，3.072 MHz |
| LRCK | FPGA 自定义 IO | 左右声道时钟，48 kHz |
| DIN | FPGA 自定义 IO | 串行数据 |
| VIN | 板卡 3.3V 或 5V | 看模块标注 |
| GND | 板卡 GND | **必须共地** |

**备选型号**

| 型号 | 优点 | 缺点 | 价格 |
|---|---|---|---|
| UDA1334A | Adafruit 有成熟模块，资料齐 | 稍贵，可能需 MCLK | 40–70 元 |
| MAX98357A | 直接推喇叭，功放一体 | D 类功放，音质一般 | 20–40 元 |
| CS4344 | 便宜 | 音质一般，资料少 | 10–25 元 |

### 2.3 喇叭怎么选（板载 MAX98357A 用）

板载功放是 **BTL 桥接输出**，对喇叭有硬性要求：

| 参数 | 要求 | 为什么 |
|---|---|---|
| **阻抗** | **8Ω（推荐）或 4Ω，必须 ≥4Ω** | 低于 4Ω 会过流，MAX98357A 会热保护甚至损坏 |
| **功率** | **≥1W，推荐 2W** | 5V 供电下 8Ω 能出 1.8W，喇叭额定功率要留余量 |
| **类型** | **动圈式扬声器（moving coil）** | 必须是线圈式的，压电蜂鸣片不行 |
| **是否带功放** | **绝对不能有源** | MAX98357A 输出已经是放大后的 PWM，再接有源音箱会出问题 |
| **出线** | **两根裸线（引线）** | SPK 是裸焊盘，得焊线；买带 XH2.54 插头的话还要再买对应插座 |

**推荐**：`8Ω 2W 直径 40mm` 圆形扬声器，带两根引线，3~8 元。
有条件的买"腔体喇叭"（带小音箱壳），声音更清楚，10~15 元。

### 2.4 在"全系列"店铺里怎么选 SKU

这类店一个链接里有几十个规格，按下面顺序挑：

| 选项 | 选哪个 | 说明 |
|---|---|---|
| **工作频率** | 🔴 **必须 0–20kHz（全频）** | **最容易踩的坑**，见下方 2.4.1 |
| **阻抗** | **8Ω 首选；4Ω 也可以** | **绝不能选 2Ω / 3Ω**，会过流烧功放。16Ω 能用但音量偏小 |
| **功率** | **2W 或 3W** | 这是"能承受的上限"，选大只是更耐用、体积更大；**别选 0.5W 及以下**，会烧 |
| **输出声压** | 越大越好（95dB 以上） | 同功率下更响，演示时不用开到最大 |
| **尺寸** | 40×20mm 以上，大一点低频更好 | 别选太小的，低频出不来 |
| **有源/无源** | **无源** | 腔体喇叭默认都是无源，但要跟客服确认一句 |

### 2.4.1 为什么"工作频率"最关键

这种店里的腔体喇叭分两大类：

| 频率标注 | 实际用途 | 用在电子乐器上 |
|---|---|---|
| `500–5000Hz` / `0–5kHz` | **广告机 / 安防喊话**（只还原人声） | ❌ **低频被砍掉**。弹 C4 (262Hz) 时基频根本发不出来，只剩谐波，声音又薄又尖 |
| `0–20kHz` | 全频段，听音乐用 | ✅ 正确选择 |

**规则：只看"工作频率"，必须是 `0–20kHz`。** 阻抗和功率这几个选项全都是 8Ω 2W，
所以唯一的筛选条件就是这个。

> 💡 **极性无所谓**：BTL 桥接输出，红黑线随便接，只影响相位不影响响不响。

> ⚠️ **关于 2P 插头**：这类喇叭出线端是 `2P_1.25` / `2P_2.0` / `2P_2.54` 插头，
> 而板上 SPK 是裸焊盘、没有对应插座。**直接剪掉插头，把两根线焊到焊盘上**即可，
> 不用为了"配插头"去挑型号。所以插头间距不是选型依据。

**直接复制发给客服**：
```
你好，我要一个 8欧 2W（或3W）、直径40mm 的腔体喇叭，
带两根引线，无源的，用来接 MAX98357A 数字功放板。有货吗？
```

**不要买**：
- ❌ 有源音箱、USB 音箱（自带功放）
- ❌ 压电陶瓷蜂鸣片 / 无源蜂鸣器（不是动圈负载）
- ❌ 耳机单元直焊（阻抗通常 16~32Ω 虽安全，但音量极小、音色怪）

> ⚠️ 这个喇叭**只用于快速验证"逻辑通不通"**。板载功放是单声道 + D 类 PWM，
> 底噪大，**不能用于频谱验证和正式演示**——那个必须走外接 PCM5102A。

## 三、第 2 批详细（交互）

### 3.1 自制电容触摸（推荐，成本低且有"自研"感）

| 物品 | 搜索词 | 预算 |
|---|---|---|
| 铜箔胶带 | `铜箔胶带 导电 单面` | 10–20 元 |
| 或覆铜板 | `覆铜板 单面 10x15cm` | 10–15 元 |
| 1MΩ 电阻 | `1M 电阻 1/4W` | 5 元 |

**原理**（纯数字逻辑，不需要专用 IC）：
```
IO 输出高 → 给触摸片充电 → 转输入 → 计数器测放电时间
手指靠近 → 电容增大 → 放电时间变长 → 判定触摸
```

**替代方案**：TTP223 触摸模块（2–5 元/个），省事但"自研"感弱。**建议自制，答辩时可以讲原理。**

## 四、第 3 批详细（力度与表情）

> ⚠️ **GW2AR-18 没有内置 ADC**。要采集模拟量必须外接 ADC 芯片。

| 物品 | 搜索词 | 预算 | 说明 |
|---|---|---|---|
| **ADC 模块** | `ADS1015 模块` 或 `MCP3008` | 15–30 元 | I2C / SPI 接口，12 位或 10 位 |
| 力敏电阻 FSR | `FSR 压力传感器 电阻式` | 15–40 元 | 力度感应 |
| 或压电片 | `压电陶瓷片 蜂鸣片` | 2–5 元 | 击打力度（便宜但线性差） |
| 霍尔传感器 | `A3144 霍尔传感器` | 5–10 元 | 配合磁铁做滑音轮 |
| 钕磁铁 | `钕铁硼 小磁铁` | 5–10 元 | 配合霍尔 |

**用比较器替代 ADC 的思路**（省钱方案）：
用 LM393 比较器 + 电容放电计时，同样能测出"力度大小"，纯逻辑实现，无需 ADC。

> 这是发挥你们机械专业优势的部分。**建议放到国赛阶段**，省赛先用电容触摸。

| 物品 | 搜索词 | 预算 | 用途 |
|---|---|---|---|
| 铝型材 | `2020 铝型材` | 20–40 元 | 框架支撑 |
| 亚克力板 | `亚克力板 定制加工` | 10–30 元 | 外壳、面板 |
| 弹簧 | `压缩弹簧 小` | 5–15 元 | 琴键回弹 |
| 轴承 | `微型轴承` | 10–20 元 | 杠杆转轴 |
| 螺丝螺母 | `M3 螺丝 套装` | 10–20 元 | 装配 |
| **3D 打印件** | 学校打印机 | 按资源 | 键帽、杠杆、支架 |
| 光电对管（补充） | `槽型光电开关` | 10–20 元 | 无接触琴键检测 |

**设计建议**：
- 琴键用杠杆结构，支点靠近一端，另一端装遮挡片
- 遮挡片插入槽型光电开关即触发
- 弹簧提供回弹力，调节弹簧预紧可改变手感
- **8 个键位起，多则更好**（对应更多音符）

## 九、采购避坑清单

| # | 坑 | 后果 | 对策 |
|---|---|---|---|
| 1 | 买了需要 MCLK 的 DAC 模块 | 电路复杂、多占 IO、可能不出声 | 买前问客服"是否 3 线 I2S 不需 MCLK" |
| 2 | DAC 逻辑电平是 5V | 可能损坏 FPGA | 确认是 3.3V 逻辑 |
| 3 | 杜邦线只买了一种 | 接不上 | 母对母 + 公对母各买 |
| 4 | 铜箔胶带绝缘层没撕 | 触摸检测不到 | 买带导电胶的 |
| 5 | 忘记共地 | 杂音、时好时坏 | 所有模块 GND 连一起 |
| 6 | 一次买齐所有东西 | 浪费钱、方向没验证 | **分批买，先验证出声** |
| 7 | 电源直接接板卡 3.3V 供 DAC | 电流不足可能不稳 | 必要时用独立 3.3V 稳压 |
