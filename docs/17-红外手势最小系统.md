# 17 · 红外手势最小系统（演奏第二维度）

> 版本：`beta.4-candidate`（2026-10-22）
> 目的：补齐赛题要求「**至少 2 个独立可控演奏维度**」里一直缺的第二维。
> 实现：`code/rtl/ir_gesture.v`｜约束：`code/constraints/synth_board12.cst`｜测试：`code/sim/tb_ir_gesture.v`

---

## 一、一句话结论

**挥手一次，换一个音色**：三角 → 方波 → 锯齿 → 脉冲 → 钢琴（环形回到三角）。

- 维度 1（原有）：12 个 TTP223 触摸键 → 选**音高**（C4~B4，含半音）
- 维度 2（本次）：红外避障模块 → 挥手切**音色**（5 档）

两维完全独立：可以一边按着和弦，一边挥手换音色。

---

## 二、硬件接线

| 模块引脚 | 接到 |
|---|---|
| VCC | **板卡 3V3**（务必 3.3V，不要 5V） |
| GND | 板卡 GND |
| OUT | **FPGA 引脚 74** |

⚠️ **两个坑**：

1. **必须用 3.3V 供电**。红外避障模块的 OUT 是 LM393 开集输出，靠上拉到 VCC；
   用 5V 供电时 OUT 高电平就是 5V，直接怼进 3.3V 的 FPGA IO。
2. **`docs/08` 里原先推荐的 30 / 77 已经不能用了** —— 12 键版把它们分配给了
   `key[3]` / `key[9]`。本次改用 **74**（该脚在 `docs/08` 曾预留为备用轻触开关，
   一直空着）。

引脚极性：模块检测到前方有物体（约 2~30 cm）时 **OUT 输出低电平**，空闲为高电平。
所以 `ir_in` 是**低有效**。

## 三、判定原理：为什么用"停留窗口"

一次**有效挥手** = 手在传感器前停留 T 后离开，且

```
80 ms <= T <= 1200 ms
```

| 情形 | 判定 | 理由 |
|---|---|---|
| T < 80 ms | 拒绝 | 手快速掠过时的输出可能是抖动/误触发，不算有意的动作 |
| 80~1200 ms | **接受** | 正常"伸一下手"的量级 |
| T > 1200 ms | 拒绝 | 手一直放在传感器前属于"遮挡"，不该反复切音色 |

选这个判据而不是"测挥手速度映射弯音"，是因为它：

- 只需 1 个数字量输入脚，不需要 ADC；
- 在仿真里可完全复现（不依赖模拟量）；
- 上板误触发率低（消抖 20ms + 窗口上下限双重约束）。

## 四、参数表（`ir_gesture.v`）

| 参数 | 默认值 | @27MHz | 含义 |
|---|---|---|---|
| `DEBOUNCE_CNT` | 540_000 | 20 ms | 输入消抖窗口 |
| `MIN_SWIPE_CNT` | 2_160_000 | 80 ms | 挥手最短停留 |
| `MAX_SWIPE_CNT` | 32_400_000 | 1200 ms | 挥手最长停留 |
| `INIT_SEL` | `3'b100` | — | 复位默认音色（钢琴，保持原有行为） |
| `N_COLORS` | 5 | — | 有效音色档数 |

顶层 `synth_board12_top` 把前三个参数又暴露成 `IR_DEBOUNCE_CNT` /
`IR_MIN_SWIPE_CNT` / `IR_MAX_SWIPE_CNT`，方便 testbench 用短时序覆盖。

## 五、接口

```verilog
ir_gesture #(...) u_ir (
    .clk, .rst_n,
    .ir_in,          // 低有效：0 = 检测到物体
    .wave_sel,       // → synth_top.wave_sel
    .gesture_valid,  // 一次有效挥手（单周期脉冲）
    .hand_level,     // 消抖后的手状态（已接到 led[3]）
    .swipe_tooshort,
    .swipe_toolong
);
```

`wave_sel` 直接接到 `synth_top` 已有的输入端（原来这里是写死的 `3'b100`），
**没有改动 synth_top / piano_engine / oscillator 任何内部逻辑**，所以音色通路
完全不受影响。

## 七、踩到的坑：`SINGLE_RESISTOR` 的 bank 限制

第一次综合直接失败：

```
ERROR (CT1117) : Attribute 'SINGLE_RESISTOR' can only be set when the port is
located to bank '2/3/6/7', but the constraint location of port 'ir_in' include other bank
Physical Constraint parsed completed with errors
```

`docs/08` 给的示例约束里带了 `SINGLE_RESISTOR=ON`，但**这个属性只在 bank 2/3/6/7 有效**，
引脚 74 不在其中。

修正：去掉 `SINGLE_RESISTOR=ON`，只留 `PULL_MODE=UP`（FPGA 内部上拉已足够驱动 LM393 的开集输出）。

## 八、上板调试顺序

```
□ 断电接线，VCC 接 3V3（量一下对 GND 是否 3.3V）
□ 只烧 synth_board12，先不接红外模块
□ 确认原有 12 键演奏正常（回归没被破坏）
□ 接上红外模块，用手靠近 —— led[3] 应该亮（hand_level）
□ 手在传感器前停约 0.3 秒后拿开 → 音色切到下一档（听声音变化）
□ 手停太久（>1.2 秒）拿开 → 音色不该变
□ 快速挥手（<80ms）→ 音色不该变
```

如果 `led[3]` 完全不亮，先查供电和 GND，再查模块上的蓝色电位器
（顺时针 = 检测距离变远；出厂已调好，别乱拧）。
