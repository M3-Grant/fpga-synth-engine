# 18 · 新硬件接线指南（TTP229 + PCM5102A + PAM8403）

> 日期：2026-10-27
> 背景：板载 MAX98357A 已损坏（±6144 就饱和，只剩满幅 18% 的输出能力），
> 触摸输入也从 12 个 TTP223 换成一块 TTP229 钢琴模块。
> 本文是**到货后照着接**的操作手册，接完按第五节的顺序验证。

---

## 一、硬件清单

| 件 | 型号 | 作用 | 状态 |
|---|---|---|---|
| 触摸 | **TTP229 钢琴模块**（99×35mm，5P） | 12 键 → 音高 | 在途 |
| DAC | **PCM5102A** 模块 | I2S → 模拟音频 | 在途 |
| 功放 | **PAM8403** 模块（3W×2） | 模拟 → 喇叭 | 在途 |
| 喇叭 | 4~8 Ω，2~3 W，**带腔体** | 发声 | 建议新买 |
| 电源 | 5V/2A 手机充电器 + USB 线 | PAM8403 独立供电 | 需自备 |
| 线材 | 杜邦线、焊好的喇叭线 | — | — |

> **喇叭那条最重要**：8 Ω 2 W 的旧喇叭很可能已经被过驱动损伤。
> 换 4 Ω 3 W 全频 + 密封后腔，比换任何电子件对音色的改善都大。

## 二、TTP229 接线（12 键 → 音高）

### 2.1 接线表

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| `VCC` | 板卡 **3V3** | ⚠️ **必须 3.3V**。接 5V 会让 SDO 输出 5V，打坏 FPGA 的 3.3V IO |
| `GND` | 板卡 GND | 共地 |
| `SCL` | 板卡 **引脚 75** | FPGA 输出 500 kHz 读时钟 |
| `SDO` | 板卡 **引脚 76** | 模块输出数据位（内部上拉） |
| `RGB` | **悬空** | 模块自带 RGB 灯的控制脚，本工程不用 |

### 2.2 位映射实测（必须先做）

TTP229 扫出 **16 位**，但"哪一位对应模块上哪个触摸点"只能实测：

```
① 烧 ttp229_debug 固件：
   cd code\synth
   .\build.ps1 -Target ttp229_debug -Program sram

② 逐個戳触摸点，读 led[3:0] 的二进制值（亮 = 1）：
     led[3:0] 亮灭 = 灭 灭 灭 亮 → 二进制 0001 → 位号 1
     led[3:0] 亮灭 = 亮 灭 灭 亮 → 二进制 1001 → 位号 9
   led[4] 亮 = 当前有键按下；led[5] 闪烁 = 心跳（证明逻辑在跑）

③ 记下：最低音（最左边白键）对应位号 = ____
         最高音（最右边键）对应位号 = ____
         以及中间各键的位号（若连续递增，写两端即可）

④ 把结果填进 code\rtl\synth_ttp229_top.v 的 TTP_BIT() 表：
     TTP_BIT(i) = 第 i 个音（i=0 是 C4）对应的 TTP229 位号
```

出厂默认假设「低音在低位、连续 12 位（0~11）」。若实测方向相反，把表改成 `15,14,13,...,4`。

### 2.3 时序参数（一般不用改）

| 参数 | 值 | 说明 |
|---|---|---|
| `SCL_HALF` | 27 clk | SCL 半周期 1 µs → 500 kHz（TTP229 上限 1 MHz） |
| `SYNC_CNT` | 5400 clk | 同步低电平 200 µs |
| `GAP_CNT` | 540000 clk | 20 ms 扫一轮 → 键状态刷新 50 Hz |

## 三、PCM5102A 接线（I2S → 模拟）

### 3.1 接线表

| PCM5102A 引脚 | 接到 | 说明 |
|---|---|---|
| `VIN` | 板卡 **3V3** | 3.3V 供电 |
| `GND` | 板卡 GND | 共地 |
| `BCK`（或 SCK） | 板卡 **引脚 56**（i2s_bck） | 位时钟 3.375 MHz |
| `LRCK`（或 WS） | 板卡 **引脚 55**（i2s_lrck） | 声道时钟 52734 Hz |
| `DIN`（或 SD） | 板卡 **引脚 54**（i2s_din） | 音频数据 |
| `LOUT` / `ROUT` | → PAM8403 的 `L-IN` / `R-IN` | 模拟音频输出 |

### 3.2 ⚠️ 四个配置脚必须接对（最常见的"接好没声"）

模块上通常是小焊盘或跳线帽：

| 引脚 | 必须接 | 接错的后果 |
|---|---|---|
| **`XSMT`** | **高（3.3V）** | 接低/悬空 → **完全静音** |
| `FMT` | 低（GND） | 接高 → 左对齐格式，声音错乱 |
| `DEMP` | 低（GND） | 接高 → 去加重，高频发闷 |
| `SCK` | 低（GND） | 接低 → 用内部 PLL 从 BCK 恢复时钟（**我们要这个**） |

> 上电第一件事：量一下 `XSMT` 是不是 3.3V。这一条占"没声音"故障的一半以上。

## 四、PAM8403 接线（模拟 → 喇叭）

### 4.1 接线表

| PAM8403 引脚 | 接到 | 说明 |
|---|---|---|
| `VIN` | **独立 5V/2A 充电器** | ⚠️ **绝对不要挂电脑 USB**（3W 输出要 700 mA，USB 只给 500 mA） |
| `GND` | 公共地 | 与 FPGA、PCM5102A、5V 电源负极全部连通 |
| `L-IN` | PCM5102A `LOUT` | 左声道 |
| `R-IN` | PCM5102A `ROUT` | 右声道（或与 L 短接，本工程左右同数据） |
| `L+` / `L-` | 喇叭两端 | **BTL 输出，两端都不能接地** |
| 音量电位器 | 先调到 **60~70%** | 留余量给数字幅度 |

### 4.2 接地顺序（决定底噪）

```
        ┌──────────── 5V 充电器 GND（功率地）
        │
   PAM8403 GND ────┬──── PCM5102A GND ────┬──── FPGA GND（3V3 板）
                   │                      │
              只在这一点汇合（星形接地）
```

- **PAM8403 的功率地单独走一根线**，在一点与系统共地
- 不要用面包板的长电源轨把大电流和小信号混在一起

## 五、上电验证顺序（照着走，出错好定位）

### 第 1 步：只验音频（不接 TTP229）

1. 接好 PCM5102A（I2S 三根 + 电源），**PAM8403 音量拧到最小**
2. 烧 `tone_test`（440 Hz 常响）：
   ```powershell
   cd code\synth
   .\build.ps1 -Target tone_test -Program sram
   ```
3. 慢慢拧大 PAM8403 音量
4. **判据**：听到清晰 440 Hz，无沙沙声

> 若这一步没声，问题一定在 PCM5102A 的跳线（先量 XSMT）或 I2S 接线。
> 与触摸、与钢琴引擎都无关。

### 第 2 步：验音色

```powershell
.\build.ps1 -Target self_test_12notes -Program sram
```

- 自动循环 12 个音（每音 0.6 s + 0.3 s 间隔）
- **判据**：能听出钢琴味、12 个音高递增、无失真

### 第 3 步：验触摸位映射

```powershell
.\build.ps1 -Target ttp229_debug -Program sram
```

- 逐键戳，读 LED 位号，填 `TTP_BIT()` 表
- **判据**：12 个触摸点都能读出**互不相同**的位号

### 第 4 步：整机

```powershell
.\build.ps1 -Target synth_ttp229 -Program sram
```

- 12 键演奏 + 红外挥手切音色
- **判据**：
  - 按不同键 → 不同音高，LED[1] 亮
  - 挥手 → 音色切换（三角/方波/锯齿/脉冲/钢琴）
  - LED[0] 心跳、LED[3] 挥手时亮

## 六、常见问题速查

| 现象 | 最可能原因 |
|---|---|
| 完全没声 | PCM5102A 的 `XSMT` 没接高 |
| 声音有节奏的"沙沙" | I2S 地线与 PAM8403 功率地混在一起，重新星形接地 |
| 声音很大但破音 | PAM8403 音量电位器拧太大，或数字幅度没降回 50% |
| 只有底噪没有音乐 | I2S 三根线接错（BCK/LRCK/DIN 顺序） |
| TTP229 完全无反应 | VCC 接了 5V 打坏 IO，或 SCL/SDO 接反（SCL 是 FPGA 输出） |
| TTP229 部分键无反应 | 位映射表填错，或该触摸点本身坏了（用 ttp229_debug 逐个确认） |
| 按键有延迟 | TTP229 扫描间隔 20 ms + 消抖 10 ms，属正常；如需更快可把 `GAP_CNT` 调到 270000（10 ms） |

## 七、固件工程一览（到货后会用到的 target）

| Target | 用途 | 需要什么 |
|---|---|---|
| `tone_test` | 440 Hz 常响，验音频链路 | 只有喇叭 |
| `self_test_12notes` | 自动循环钢琴十二音 | 只有喇叭 |
| `self_test_square` | 自动循环方波十二音（对照用） | 只有喇叭 |
| `ttp229_debug` | 触摸 → LED 显示位号 | TTP229 |
| `synth_ttp229` | 完整整机（12 键 + 红外） | TTP229 + 红外 + 音频 |

全部用 `-Program sram`（掉电即失）或 `-Program flash`（持久）。
